# Dickens_Portfolio

A modern, responsive personal portfolio built with **React**, **Vite**, and **Tailwind CSS**.  
Showcases my projects, skills, experience, and contact info.

## ✨ Features

- **Fast**: Powered by Vite for instant HMR and optimized builds
- **Responsive**: Mobile-first design with Tailwind CSS
- **Dark/Light Mode**: Toggle theme with localStorage persistence
- **Sections**: Hero, About, Skills, Projects, Experience, Contact
- **Smooth Animations**: Framer Motion for transitions
- **SEO Ready**: React Helmet for meta tags
- **Contact Form**: Email integration with [EmailJS / Formspree]

## 🛠 Tech Stack

| Category | Tech |
| --- | --- |
| Framework | React 18 + Vite 
| Styling | Tailwind CSS 
| Icons | React Icons / Lucide 
| Animations | Framer Motion
